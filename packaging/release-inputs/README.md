# Native runtime build inputs

These generated headers are the pinned inputs for the 1.0 build. The shared
headers were used in the archived 2D and exemplar runtimes and the approved
Christmas runtime. Their generators are in [cadet/game](../../cadet/game/)
and [cadet](../../cadet/). The cover data files were generated by
[pack_music_cover.py](../../cadet/game/pack_music_cover.py) for the 2 MB standard
and exemplar music. They must match the command stream and PCM in the
archived runtime ZIP. The lamp position file holds only the geometry needed
by the holiday lamp generator.

The [archive manifest](../../releases/1.0-Beta/Emulator/RAM-and-Quit/PACKAGE-MANIFEST.json)
tracks the runtime data used alongside these headers. See the repository
license and the archive notices for the scope of each attribution.
