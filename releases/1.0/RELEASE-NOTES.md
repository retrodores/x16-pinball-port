Space CmdrX16 2D Pinball 1.0 for the Commander X16 is available in standard
and Christmas editions.

| ZIP | Banked RAM |
| --- | --- |
| `SpaceCmdrX16-2D-Pinball-1.0-512KB.zip` | 512 KB |
| `SpaceCmdrX16-2D-Pinball-1.0-2MB.zip` | 2 MB |
| `SpaceCmdrX16-2D-Pinball-Christmas-1.0-2MB.zip` | 2 MB |

Choose one ZIP and extract it to its own directory. Every package includes
`PINBALL.PRG`, the companion files and a Windows launcher. The launcher
expects x16emu r49 and its matching ROM in the parent directory. From X16
BASIC in the game directory, enter `LOAD"PINBALL.PRG",8,1` and then `RUN`.

The Christmas edition features the winter cabinet and a 74-second
*Carol of the Bells* arrangement with synchronized lamps and brief laser
accents. The standard 2 MB edition uses the expanded soundtrack.

Hold and release **Space** to launch, use **Z** and **/** to flip, **F2** to
start a game, **F3** to see the demo, **M** to toggle music, and **Q** or
**Esc** to return to BASIC.

Tested with x16emu r49 on Linux, using an 8 MHz 65C02 and the stated RAM.
Some frames exceed the frame budget. See the [wiki](https://github.com/retrodores/x16-pinball-port/wiki) for
setup and the [checksums](https://github.com/retrodores/x16-pinball-port/blob/v1.0/releases/1.0/SHA256SUMS)
for download verification.
