# X16 Pinball Cover Balance Preview

These are the 2 MB Space Cadet X16 and Space CmdrX16 Backbox builds with a
revised mix. Both restore the three native soundtrack banks from the
Attract Fidelity Preview. The PCM mixer raises the effects by about 2 dB,
with headroom for stereo drums. The newest backbox artwork and red BALL
lettering are included.

Extract either ZIP into its own folder. Put x16emu.exe and its matching
rom.bin in the parent folder and double-click RUN-WINDOWS.bat. The 512 KB
builds remain available in the Backbox Preview.

Both ZIPs passed fresh-extraction smoke tests on Linux r49. Windows
launcher execution remains unverified. The recording supplied for the
comparison had a single stereo audio track for both games. Per-game
Windows and X16 gain measurements require separate captures. See
VALIDATION.json for the controlled X16 tests and remaining timing limits.
