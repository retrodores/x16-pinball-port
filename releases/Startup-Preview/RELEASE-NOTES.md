# X16 Pinball Startup Preview

Cold start and F2 now run a five-second lamp show across the supported
playfield lamps and center rings. The message panes stay blank during
the show. The player label appears first, then about one second later
the existing ball-feed sound plays and the plunger prompt appears.
The show uses four original interleaved lamp phases. F2 skips an active
show and F3 enters the demo.

The enhanced Windows recordings showed approximately five seconds to
the player label on two cold starts and two new-game resets. Those
observations set the X16 stage durations. The X16 uses its current
soundtrack and ball-feed cue. A dedicated opening sound and the remaining
mission and jackpot choreography are outside this preview.

The 512 KB ZIPs use the standard soundtrack. The 2 MB ZIPs carry the
calibrated Cover Balance mix. Both editions include the latest backbox
art and red BALL label.

Extract the selected ZIP into its own folder. Put x16emu.exe and the
matching rom.bin in the parent folder and double-click RUN-WINDOWS.bat.
This development preview was checked on Linux r49. Windows launcher
execution remains unverified. The extended 133,333-cycle timing target
remains open. See VALIDATION.json for the tests run on this build.
