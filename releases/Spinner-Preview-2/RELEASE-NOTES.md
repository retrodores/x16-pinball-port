# X16 Pinball Spinner Preview 2

The opening red X now overlays the upper blue X insert beside the center
rings. Preview 1 lit a separate location farther down the left slingshot.
The placement change applies to Space Cadet X16 and Space CmdrX16.

Extract the ZIP for your edition and RAM size into a new folder. Put
x16emu.exe and its matching rom.bin in the parent folder, then run
RUN-WINDOWS.bat. The 512 KB edition uses the compact soundtrack. The
2 MB edition uses the credited cover soundtrack.

The Linux r49 emulator checks compare the flashing red pixels with the
unlit blue insert, check the old location, and exercise cold start and F2
on the extracted runtimes. The Windows launcher remains untested on Windows.

The earlier extended timing runs exceeded the 133,333-cycle budget at
both RAM sizes. Preview 2 retests the lamp placement and spinner fixtures.
Skill shots, wider lamp coverage, independent status messages, the center
drain blocker, the spinner score boost and advanced mission triggers
remain open.
