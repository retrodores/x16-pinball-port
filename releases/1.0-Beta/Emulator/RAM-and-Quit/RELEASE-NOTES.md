# 1.0 Beta

This emulator beta checks for banked RAM before loading assets. It explains
the 512 KB or 2 MB requirement and suggests the compact edition when applicable.
Press Q or Escape to return to BASIC. BASIC can load another program after exit.

Extract the ZIP into its own folder. Place x16emu r49 and its matching rom.bin
in the parent folder. On Windows, double-click RUN-WINDOWS.bat. The launcher
selects the CPU and RAM size shown in the archive name and runs PINBALL.PRG
at 8 MHz. The 65C816 editions use the same PRGs in 6502 compatibility mode.
Physical hardware and the Windows launcher have yet to be tested.

The 2 MB editions include the full X16 cover soundtrack and its credits.
The 512 KB editions use the compact soundtrack. Busy scenes can exceed
the 133,333-cycle frame budget.
