# 1.0 Beta

Emulator tester build for x16emu r49. Extract the ZIP to its own folder, keep
`x16emu.exe` and its matching `rom.bin` in the parent folder, and run
`RUN-WINDOWS.bat`. The launcher selects a stock 65C02 at 8 MHz and the
RAM size shown on the ZIP. Physical hardware validation is pending.

The 2 MB editions include the full Commander X16 cover soundtrack and
`MUSIC-CREDITS.txt`. The 512 KB editions use the compact soundtrack.
Busy scenes can exceed the 133,333-cycle frame budget.

The game starts from `PINBALL.PRG` in each ZIP. The executable bytes,
overlays, assets, and notices match the previous 1.0 Beta emulator builds.
