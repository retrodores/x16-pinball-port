# X16 Pinball Center and Demo Preview

Choose Space Cadet X16 or Space CmdrX16. The 512 KB ZIP uses the standard
soundtrack. The 2048 KB ZIP uses GTR3QQ's native stereo cover and brings the
game effects forward. Each ZIP is complete and includes RUN-WINDOWS.bat.
Put x16emu.exe and its matching rom.bin in the parent folder.

- Demo flippers react to the ball's approach, with distinct timed holds.
- The center rings show rank and animate during first-rank Target Practice
  and Launch Training. Other mission and jackpot sequences remain incomplete.
- Both backbox panes use the score and BALL sprites for digits. Mixed-case
  letters use an authored face with the same palette and sparse stipple.
- The isolated flipper effect measured 6.03 dB above the initial cover build.
  The soundtrack gains are unchanged. The Windows recordings have different
  capture levels, and their combined audio does not give isolated mix ratios.

The native 65C02 r49 runs used 8 MHz. Both editions passed fresh-extraction
Linux tests. Windows launcher execution is unverified. The 2048 KB test
completed two full cover loops with zero reported PCM underruns. The frame
budget is still exceeded. See VALIDATION.json for counts and provenance.

The 2048 KB ZIPs credit Matt Ridgeway for the composition and GTR3QQ for the
X16 cover. The cover is under CC BY-SA 4.0. See MUSIC-CREDITS.txt in those ZIPs.
